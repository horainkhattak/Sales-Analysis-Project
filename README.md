This project presents a comprehensive sales analysis performed in Excel using Pivot Tables and Pivot Charts to evaluate sales performance across different occasions such as Eid, Birthday, Anniversary, and Valentine’s Day. Key performance indicators including total revenue, average revenue, and total number of orders were calculated to understand overall business performance. The analysis explores product category performance such as Cakes, Colors, Soft Toys, and Sweets to identify top-performing segments. City-wise sales distribution and monthly trends were visualized to highlight regional and seasonal patterns. Additionally, day-wise order analysis was conducted to identify peak sales days. An interactive dashboard was developed using slicers for dynamic filtering by occasion and date. The project provides meaningful insights to support data-driven business decision-making.
